SikaMTV 用于将背景图片或视频、音乐和歌词快速合成为音乐视频。它提供实时预览、动态歌词、多种音频可视化和背景轮播效果，并可一键导出标准 MP4 文件。

项目采用 Swift 和 Apple 原生框架开发，不依赖 FFmpeg 或第三方运行时。

## 功能特性

### 素材库与工作区

- 左侧统一资源管理器集中管理图片、视频、音乐和歌词文件，支持搜索、类型筛选和资源计数。
- 一个导入入口可同时选择多种类型、多个文件，也支持直接拖入资源管理器。
- 只有拖入中央“项目素材”工作区，或点击“加入工作区”的资源才会参与预览和导出。
- 工作区按画面背景、主音乐、歌词字幕三个标准槽位组织，显示就绪状态、素材摘要和清理操作。
- 支持一次导入多张图片或多个视频，并允许图片与视频混合使用。
- 根据音乐时长和素材数量自动安排每个背景的展示区间。
- 提供淡入淡出、横向滑动、缩放溶解和直接切换效果。
- 视频背景可自动循环；单视频循环点默认使用首尾交叉淡化，减少生硬跳切。静态图片可应用缓慢缩放，避免画面完全静止。
- 背景视频声音默认关闭，可按需开启并独立调节混音音量。
- 支持背景模糊、四角暗化和饱和度调节；暗化采用电影式边缘渐变，不再给整幅画面覆盖黑层。
- 静态图片默认启用 Vision 智能模糊：复用导入阶段缓存的人脸与显著主体遮罩，让主体保持清晰、环境按模糊强度柔化；视频背景继续使用高性能普通模糊。
- 五套模板默认不再向背景叠加主题色，避免与原图色彩冲突；模板配色仅用于音频可视化和文字光晕。
- 提供独立的背景色彩遮罩，可自行选择颜色与强度，默认强度为 0、完全透明。
- 对阳光、高光等明亮区域应用亮部保护与柔和压缩，减少 Bloom、光流和节拍冲击叠加造成的过曝。
- 静态背景生命系统通过独立 Metal 背景着色阶段加入音乐驱动的 2.5D 镜头呼吸、亮度视差、局部涟漪、节拍冲击和流动光影，前景可视化与歌词保持稳定。
- 提供自然、沉浸、液态和关闭四种背景模式，并可调节生命力、镜头呼吸、音频形变、空间视差、光流和智能主体保护；视频背景会自动降至低强度。
- 默认背景运动已调整为稳定的慢呼吸，并降低音频形变、光流和瞬态折射，减少静态图片随节拍跳动。
- 使用 macOS 原生 Vision 在图片导入阶段识别人脸与视觉显著主体，生成 256×256 柔性保护遮罩并缓存到本机；该遮罩同时用于智能模糊、运镜和形变保护，逐帧 Metal 渲染不会重复执行视觉分析。
- “Vision 主体分层”只负责让音频可视化进入主体后方并沿轮廓包光，不会修改用户设置的歌词或视觉位置。
- 在支持前景实例分割的 macOS 上自动使用更精细的主体遮罩，旧系统回退到显著性与人脸分析；预览和导出共用同一份缓存结果。

### 音频可视化

- 模板、可视化类型、位置、大小和响应强度均由用户直接控制，选择或拖动后立即生效，不存在额外导演层覆盖参数。
- 背景色彩融合会从背景提取主色、第二主色、色相跨度、冷暖、亮度与饱和度，再调和音频可视化、片头和歌词光晕；它不会改变背景色彩，也不会自动开启背景遮罩。
- 场景综合色组只分析并缓存一次，不在逐帧渲染中重复计算。
- 使用 Accelerate/vDSP 执行 4096 点 FFT，并生成 96 个频段。
- 提取响度、低中高频、节拍和波形等实时特征。
- 音乐结构引擎从全曲识别安静段、能量曲线、瞬态、蓄势、高潮、音色冷暖和段落进度，让视觉随音乐叙事发展，而不是只跟随瞬时音量跳动。
- “音乐感知”参数用于控制结构响应程度；安静段自动收敛，蓄势段增加流动，高潮增强空间、色彩与光晕，强瞬态触发短促冲击。
- 分析结果使用本地二进制缓存，减少重复加载和切换音频时的等待。
- 内置 11 种 Metal 音频可视化：丝绸波形、动态频谱、镜像地平线、呼吸光环、液态水波、极光帷幕、棱镜隧道、星尘星云、万象花镜、星河跃迁和流光边界。
- “流光边界”把多层低透明频谱线、角落漫射和边缘光带环绕在画面四周，在保留中央主体的同时形成整体包裹感；光线采用宽幅衰减和背景综合色组，避免生硬描边。
- 可视化采用低频、中频、高频、响度和节拍分层驱动，并通过半透明色场与背景融合。
- 静态图片支持主体前后分层：音频可视化先绘制在背景空间，主体随后重新合成到前方，并从原图颜色生成音乐驱动的柔和轮廓光。
- Visual Engine 2.0 使用统一的 Metal 多阶段渲染，将背景折射、三尺度电影级 Bloom、轻微色散、短时残影、动态颗粒和色彩调校应用于全部效果；歌词在后期之后独立合成，保持清晰可读。
- Nebula 与 Starfield 采用时间连续的粒子轨迹、渐入渐出生命周期和弧形尾迹；音乐控制亮度、尾迹与空间冲击，不会因瞬时响度变化造成位置跳动。
- 段落内部会进行克制的动态配色演进，并结合音乐冷暖、蓄势与高潮改变光影氛围，避免整首视频保持完全相同的色调。
- 常用区域只保留类型、响应、位置、大小和光晕；音乐感知、平滑、炫丽度、背景融合与拖尾统一收进高级设置。
- 提供 Zen、Ethereal、Minimal、Cinema 和 Electronic 整体视觉模板。

### 歌词与字幕

- 支持标准 LRC 歌词和 SRT 字幕。
- 可自动查找与音频同名的歌词或字幕文件。
- 同时显示上一句、当前句和下一句，并突出当前歌词。
- 支持歌词字号、位置、行距、对齐、透明度和动画参数调节。
- 提供向上滚动、交叉淡入、呼吸缩放、逐字点亮、光晕绽放和无动画模式；默认使用连续上移。
- 除“无动画”外，上一句和当前句会在时间点同步退场与入场，避免字幕状态生硬跳切；动画时长位于歌词常用设置区。
- 内置项目提供的“素材集市康康体”作为默认歌词字体，并通过 CoreText 在 App 进程内注册。
- 支持 macOS 系统字体，以及用户导入的 TTF/OTF 字体。

### 片头信息

- 可在右侧“片头”Tab 输入歌名和作者；作者默认填写为“鹿鸣松(Lumisum)”。
- 导入音乐时可自动使用音乐文件名作为歌名，也可随时一键恢复为文件名。
- 可显示本次生成日期，统一采用 `yyyy-MM-dd` 格式。
- 片头在开场自动淡入淡出，并提供流光上浮、电影淡入和简约显现三种动画。
- 片头默认显示 12 秒，歌名默认使用更醒目的 72pt 字号。
- 竖屏与方形视频自动在顶部居中排版，横屏视频自动放在左上角。
- 片头使用局部自适应暗衬和模板配色光晕，在明亮背景上仍保持清晰，同时不会破坏主体画面。

### 预览与导出

- 支持 9:16、16:9 和 1:1 画面比例。
- 预览画布严格使用当前导出比例，确保所见即所得。
- 预览与最终视频共用同一套 `RenderEngine`。
- 播放时采用轻量实时预览，暂停后自动恢复高清预览。
- 使用连续视频解码、Metal 加速的 Core Image 滤镜和硬件 H.264 编码，减少多视频项目的等待。
- 默认导出 1080P、30 FPS、H.264 + AAC 的 MP4 视频。
- 导出过程中显示实时进度和已处理时长，并可随时停止生成。
- 导出完成后可直接播放视频或在 Finder 中显示。
- 右侧面板仅直接展示常用参数，背景、视觉、歌词和片头的专业参数统一放入折叠式高级设置。

## 使用流程

1. 点击左侧资源管理器的“+”，一次选择需要的图片、视频、音频和字幕文件。
2. 使用搜索和类型筛选找到素材，再拖入中央“项目素材”工作区；也可以点击素材右侧的“+”。
3. 确认画面背景、主音乐、歌词字幕三个槽位均显示为已就绪。
4. 默认使用内置“素材集市康康体”，也可在右侧“歌词”Tab 切换系统字体或导入 TTF/OTF。
5. 在“片头”Tab 确认歌名、作者和生成日期，并选择片头动画。
6. 选择视觉模板和可视化类型，再按需要调整响应、位置、大小与光晕；所有参数都会直接生效。
7. 选择输出比例，确认实时预览效果。
8. 点击“生成视频”并选择保存位置。

## 支持格式

| 类型 | 格式 |
| --- | --- |
| 背景图片 | JPG、JPEG、PNG、HEIC |
| 背景视频 | MP4、MOV |
| 音频 | WAV、MP3、M4A、AAC、AIFF、FLAC |
| 歌词与字幕 | LRC、SRT |
| 用户字体 | TTF、OTF |
| 导出视频 | MP4（H.264 + AAC） |

## 技术架构

| 模块 | 职责 |
| --- | --- |
| `MediaManager` | 文件选择和素材元数据读取 |
| `WorkspaceState` | 素材库、工作区和播放状态管理 |
| `LRCParser` | LRC 与 SRT 解析和时间轴标准化 |
| `FontManager` | 系统字体枚举与外部字体动态注册 |
| `AudioAnalyzer` | FFT、波形、频段和节拍分析 |
| `SceneColorAnalyzer` | 缓存背景综合色组，用于视觉和文字光晕的非侵入式配色融合 |
| `VisualizerEngine` | 音频可视化图形生成 |
| `RenderEngine` | 统一合成背景、可视化、片头信息和歌词 |
| `PreviewRenderer` | 实时预览调度和帧渲染 |
| `VideoExporter` | H.264/AAC 视频编码与进度管理 |

主要使用 SwiftUI、AVFoundation、Accelerate/vDSP、Core Image、Core Text 和 AVAssetWriter。

## 系统要求

- macOS 13.0 或更高版本
- Swift 6.0 或兼容版本
- Xcode 16 或兼容的 Swift 工具链

## 本地运行

```bash
git clone https://github.com/lumisum/sikamtv.git
cd sikamtv
swift run MTVMusicVideo
```

## 打包为 macOS App

项目提供了可直接使用的打包脚本：

```bash
./scripts/package_app.sh
```

完成后，应用位于 `dist/SikaMTV.app`。

常用参数：

| 参数 | 作用 |
| --- | --- |
| `--open` | 打包完成后立即打开 SikaMTV |
| `--install` | 将应用复制到 `/Applications` |
| `--debug` | 使用 Debug 配置打包，便于开发调试 |
| `--version X.Y.Z` | 设置本次打包的应用版本号 |

例如，打包最新版本并立即启动：

```bash
./scripts/package_app.sh --open
```

首次运行时，如果 macOS 阻止打开未签名的本地应用，可运行测试启用脚本：

```bash
./scripts/enable_tests.sh
```

## 测试

运行全部自动化测试：

```bash
swift test
```

测试覆盖歌词与字幕解析、片头动画与横竖屏布局、音乐结构识别、背景轮播调度、可视化参数、统一后期稳定性、输出比例、预览/导出方向和核心渲染性能。

## 素材与字体版权

SikaMTV 只负责使用用户提供的素材生成视频，不提供素材授权。请确保你对导入的背景图片、视频、音乐和字体拥有当前作品所需的合法使用权。

应用内置项目提供的“素材集市康康体”作为默认字体，字体仅在应用运行期间通过 CoreText 注册，不会安装到整个系统。正式分发 App 前，项目发布者仍需确认该字体许可证允许将字体文件随软件重新分发。用户导入 TTF/OTF 字体时，也应自行确认作品使用授权。

## 隐私与依赖
